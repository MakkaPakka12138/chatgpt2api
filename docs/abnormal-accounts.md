# 异常账号列表

管理员导航新增“异常账号”，地址 `/accounts/abnormal`。

原来的 `auto_remove_invalid_accounts` 开关为真时会直接删除异常账号。现在保留同一配置键，将账号移出调度池并保存到异常列表。未开启开关时，号池中标为“异常”的账号同样出现在此页面。`auto_remove_rate_limited_accounts` 开关也改为保留自动移出的限流账号。

页面显示邮箱、套餐、来源、状态、异常原因和记录时间，支持搜索、分页、刷新、验证恢复和手动删除。

隔离记录与活跃账号使用同一存储后端，保留刷新 token、密码等原有资料，并随现有备份保存。隔离账号不参与轮询、额度筛选或账号批量刷新；服务重启后仍保留。页面 API 仅返回展示所需字段，不返回密码、刷新 token 和身份 token。

“验证并恢复”使用现有 token 刷新及远端账号验证逻辑；验证期间账号标为异常，验证通过才恢复到号池。未通过验证的资料继续保留；token 已无法刷新时，可通过现有 OAuth 登录或重新导入流程补充有效凭据。手动删除需在页面确认，删除后本地记录才会清除。删除 API 会保护已恢复的正常账号，避免过期页面误删。

以前已经直接删除的账号不能自动恢复，可从原有备份或账号源重新导入。新功能不会读取日志猜测或重建凭据。

管理员 API：

- `GET /api/accounts/abnormal`：读取异常和自动隔离的记录。
- `POST /api/accounts/abnormal/recover`：传入 `tokens`（1–20 个），验证并恢复，返回成功数、错误和最新异常列表。
- `DELETE /api/accounts/abnormal`：传入 `tokens`，明确删除仍处于异常或隔离状态的记录。
