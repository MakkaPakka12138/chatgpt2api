# 浏览器时区

前端时间展示使用浏览器当前时区，不固定为服务器时区或 UTC+8/UTC+9。
适用于日志列表与详情、账号创建与额度恢复、异常记录、图片管理、会话历史、
调试任务、备份、用户密钥、导入任务及代理检测/迁移记录。

历史服务器记录没有时区的时间字符串按 UTC 解析，因为原部署容器一直使用 UTC。
有 Z 或明确偏移的 ISO 时间保留原本代表的时刻，转换时只应用一次偏移。
新日志和图片任务使用带 +00:00 的 UTC ISO 时间，旧记录和图片文件无需迁移。

浏览器日期筛选生成当地零点的 UTC start_at，以及结束日期次日零点的 UTC end_before。
结束边界为排他边界，支持夏令时导致的 23/25 小时日期。
日志查询、图片查询及按日期删除图片使用相同边界；旧 start_date/end_date API 参数继续兼容。
服务器时区、上传冷却时长、额度恢复时刻和上游请求中的时区参数不因显示变化而改变。

示例：原 UTC 日志 2026-10-01 05:10:58，在 Asia/Tokyo 浏览器显示 2026-10-01 14:10:58，
在 America/Los_Angeles 浏览器显示 2026-09-30 22:10:58。
