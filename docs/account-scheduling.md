# 账号调度模式

在设置页面的“账号调度模式”选择后保存，立即应用于后续文本和生图请求。配置字段 `account_scheduling_mode` 支持 `round_robin`（默认）和 `sequential`。旧配置没有此字段时继续轮询。

- 轮询：按原规则分散请求；带参考图时仍优先选择已完整缓存参考图的可用账号。
- 顺序使用：按账号存储顺序，每次优先选择第一个满足条件的账号；可用时持续使用，生图额度耗尽、账号异常、套餐不匹配或本次重试明确排除该账号时，使用后续账号。新上传余量低于20的账号放入备用队列，在没有可立即使用的优先账号时尝试，且须足够上传本次未缓存参考图。顺序模式在每个额度队列内保持账号顺序。

顺序使用保留单账号并发限制：前面的账号忙且槽位已满时，使用后续有空闲槽位的账号；前面的账号恢复可用后会重新获得优先级。它不将所有请求串行排队，也不改变生图失败重试规则。已有完整参考图缓存不消耗上传额度，仍按原规则可用。

文本对话没有准确的剩余对话额度判定，顺序模式会持续选择前面的可用账号；原有鉴权失效重试会排除已尝试账号，但普通文本限流或网络错误不会因此新增切号重试。
