# 可选代理池

入口：设置 → 代理池。默认关闭；关闭时保持原有账号专属代理和统一代理的优先级。
开启后，没有专属代理的账号自动分配已经检测通过的池内代理。多个账号可共享一个代理，
已有绑定持久化在 `data/proxy_pool.json`，不因重启或 token 刷新重新随机分配。
代理池为空、未检测通过或全部异常时，回退到原有统一代理。

号池管理的账号信息中显示当前代理和检测到的出口 IP。编辑账号可选择自动分配、统一代理、
池内具体代理或原有手填专属代理。手动选择池内代理也参与故障迁移。
已设置手填专属代理的账号不会被自动覆盖；若要加入池管理，可改选自动分配。

每 300 秒进行轻量检测：查询出口 IP，访问 ChatGPT CSRF 接口并检查有效响应。
不发起生图、不上传参考图。单独的 IP 查询失败不判定代理坏了。
403/429 标记目标访问受阻，不视为可用。上游 500 不直接判定出口故障。
实际连接错误会触发提前检测；连续 3 次检测确认异常后暂停代理，将整批绑定账号迁移到
同一个健康备用代理。没有备用时使用统一代理，后续可自动分配恢复健康的节点。
冷却 300 秒后重测，连续 2 次通过才恢复；原账号不会自动搬回，避免来回切换。

账号当前已创建的请求会话固定原出口。自动切换针对后续会话，沿用现有失败重试机制，
不会单独重新提交已经成功的生图任务。密码重新登录与 token 刷新也使用该账号的代理。
每个节点可设置生图并发上限，同一检测出口 IP 的多个节点共享最小并发上限。
上传额度、图片额度、账号轮询/顺序模式及参考图复用规则保持原样。

代理 URL 支持 HTTP、HTTPS、SOCKS5（远端 DNS），以及 主机:端口:用户:密码 格式。
必须使用服务器容器能访问的地址，容器的 127.0.0.1 并不代表宿主机。
动态代理是否保持实际出口取决于代理商会话配置，固定地址本身不能保证固定公网 IP。

管理接口均要求管理员鉴权：

- GET `/api/proxy-pool`
- POST `/api/proxy-pool/settings`：enabled、check_interval_seconds
- POST `/api/proxy-pool/nodes`：name、url、enabled、max_concurrency
- PUT/DELETE `/api/proxy-pool/nodes/{id}`
- POST `/api/proxy-pool/nodes/{id}/check`
- POST `/api/accounts/update`：新增可选字段 proxy_pool_choice（auto/global/legacy/节点 ID）

列表不返回代理用户名或密码，编辑时 URL 留空表示保留原值。
状态文件使用私有权限并原子替换，服务器备份应通过容器读取私有文件。
